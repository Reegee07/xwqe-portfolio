# xwqe — Web Portfolio

Четыре концепт-сайта в портфолио **xwqe**: три промо-концепта для
видеомонтажа и интерактивный фотографический лендинг.
Первые три основаны на шаблонах из статьи
[teletype.in/@singularyx/24VIBECODINGVIDEO](https://teletype.in/@singularyx/24VIBECODINGVIDEO)
(Lumora / Laocoön / Loopstack), переработаны под тематику видеомонтажа.

Каждый сайт — один самодостаточный `index.html`, без сборки и фреймворков.

## Структура

| Папка | Концепт | Что внутри |
|---|---|---|
| `index.html` | Хаб | Тёмная стартовая страница со ссылками на все четыре сайта |
| `lumora/` | **xwqe studio** — светлый студийный лендинг | Лоадер с счётчиком, liquid cursor-reveal хиро, карусель, услуги (монтаж/цвет/моушн/звук), портфолио, статистика с count-up, модалка заявки, Lenis smooth-scroll |
| `laocoon/` | **Cut and Time** — кинематографичный манифест | Three.js: бронзовая скульптура, 360° орбита камеры на скролле (900vh), шейдер жидкой бронзы, 450 искр, per-letter blur-reveal заголовки, кастомный курсор |
| `loopstack/` | **xwqe hero** — один экран | Видео-фон, гигантский вордмарк xwqe с letter-reveal, неоновый акцент `#39FF14`, glassmorphism-курсор «SAY HELLO!» |
| `tatsuo/` | **Tatsuo Suzuki** — фотоархив | Статический экспорт Next.js-лендинга: 3D-колесо фотографий, WebGL dissolve заголовка, GSAP/ScrollTrigger, полноэкранные переходы между кадрами |

## Запуск

Любой статический сервер из корня проекта:

```
python -m http.server 8641
# → http://localhost:8641
```

Открывать через сервер (не file://) — laocoon использует ES-модули (importmap).
